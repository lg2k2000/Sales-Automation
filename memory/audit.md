# Desk Monkey Self-Audit

Weekly findings written by `routines/self-audit`. Each section is headered `## Week ending <YYYY-MM-DD>` and contains:

- Recurring drift patterns worth a prompt patch
- One-off errors (don't patch)
- Healthy patterns to preserve

The self-audit routine never re-audits a week already present here. Liam reviews findings and applies prompt patches manually.
